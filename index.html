TRANSPARENCY

Model methodology

A responsible prediction system reports what it knows—and what it does not.

01 / DATA

Dataset quality

Use reliable crop-yield records with consistent units, regional coverage and clearly documented sources. Missing fields and outliers require review.

02 / MODEL

Fair comparison

Compare a baseline such as Linear Regression with tree-based models using the same held-out test data.

03 / VALIDATION

Honest evaluation

Report MAE, RMSE and R² only after evaluation on unseen real data. Random splits may overstate performance when records share locations or years.
